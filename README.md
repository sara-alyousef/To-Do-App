# To-Do List App 🗒ᝰ.ᐟ

A small command-line app for managing daily tasks.

## ✿ Run

Requires Python 3.

```bash
python todo.py
```

On some systems, use `python3 todo.py`.

## ✧ Usage

- `1` — Add tasks
- `2` — View tasks
- `3` — Remove tasks
- `4` — Quit (saves your tasks)

Type `done` to stop adding or removing tasks. Tasks are saved in `tasks.txt`.
